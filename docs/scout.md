# SCOUT：新领域文献调研指南

从“对这个领域不熟”到“能够与导师讨论研究问题”的轻量工作流。来自一次湍流重构调研的实践，适用于方法与实验研究；具体分类和阅读量随课题调整。

**调研要交付的是一幅有证据的问题地图：大家在解决什么，现有方法做到哪里，重要困难在哪里。** 收集论文、整理工具和生成报告，都服务于这个目标。

## 1. 先确定这轮调研要支持什么讨论

用几句话写清：研究对象、现实动机、已有条件、希望通过调研弄清的问题，以及会议时间。暂时分不清的概念直接记为问题。

这一轮可以只支持“确定值得研究的任务”，不必同时确定模型、实验方案和创新点。把导师的背景建议与本轮实际工作范围分开记录。

## 2. 用少数入口论文建立领域地图

先找一篇能解释主线的综述，再选经典方法与近期代表作，沿参考文献回看来源、沿后续引用追踪发展。保存检索词和检索日期，便于补查。

检索线按**问题、输入条件和用途**划分。主线多读一些；邻近领域先用一两篇综述或代表作理解关系。不要把某次调研的“四条线”或论文数量固定成所有领域的规则。

一篇论文可以有多个主题标签，只保留一个稳定编号。同一研究的预印本与期刊版记录版本关系，避免重复计数。

## 3. 先泛读，把论文放到同一张地图上

先看摘要、引言中的动机、任务设置、关键图表与结论。每篇至少回答：

| 问题 | 为什么要记录 |
| --- | --- |
| 研究什么对象，解决什么问题？ | 防止同名方法实际做的是不同任务 |
| 输入从哪里来，训练和使用时分别知道什么？ | 弄清数据来源、监督条件和信息成本 |
| 希望输出什么，以什么判断有用？ | 把目标与评价指标连接起来 |
| 核心方法是什么，关键设计解决哪个困难？ | 理解方法的理由，而不只记网络名称 |
| 在什么条件下获得什么效果？ | 结果须与任务规模、基线和适用范围一起读 |

泛读只需足够决定“重点读、背景参考、暂缓”。未核实的地方写“待确认”，再回原文定位；不必第一遍填满所有超参数。

使用：[领域地图与文献索引模板](../templates/field-map.md)。

## 4. 重点论文用两层笔记来读

**第一层是一段话**：什么模型，在什么输入条件下，解决了多大规模的问题，取得了什么改善，主要限制是什么。它应当足以支持会议上的简洁介绍。

**第二层围绕证据展开**：

1. 画清“输入 → 关键处理 → 输出”，把训练流程与实际使用流程分开。
2. 找到主要对照：作者改变了什么，保持了什么，实验能否说明这一设计的作用？
3. 选择几张关键图，每张回答“横纵轴／颜色代表什么、比较了什么、支持什么结论”。
4. 记录任务规模、指标定义、主要结果及原文页码，补上失败情形、代价和有效范围。
5. 观察论证顺序：如何引出问题、提出设计、安排基线与消融，再用哪些图解释结果。以后 follow 的是这种论证组织。

遇到生词，先解释它在当前论证中的作用；影响理解的基础概念集中补一页。公式只深入到足以理解关键机制、指标或限制的程度。

使用：[单篇阅读模板](../templates/paper-note.md)。综述侧重分类、发展动机与争议，不强行填“模型效果”。

## 5. 跨论文比较，形成自己的综合认识

按“输入—目标—方法”重新组织材料，再回答两类问题：

- **为什么发展出这些方法？** 前一种做法遇到什么困难，新方法增加了什么信息、约束或能力？不同路线往往并行，不能简单排成升级链。
- **哪些困难反复出现？** 为什么影响用途，哪些论文提供证据，已有工作解决到哪一步？同时考虑数据、泛化、计算成本和实际使用条件。

比较结果前先检查任务、数据来源、指标定义和基线是否可比。某篇论文没有做某事，只能说明其范围；“整个领域尚未解决”需要更广的检索依据。对发展趋势也要区分“多项工作共同支持”与“少数论文提出的方向”。

## 6. 汇报时，把材料压缩成可讨论的问题

一个实用结构是：**领域动机 → 输入条件 → 输出目标 → 方法及局限 → 共同困难 → 必要基础概念**。重点论文可以各配一段简介和少数关键图，详细参数留在单篇笔记。

最后列出尚未确定、需要讨论的问题。先把问题说清楚，再与导师讨论 idea；不必为了让汇报显得完整，提前指定网络或把猜测写成研究空白。

使用：[综合汇报模板](../templates/review-report.md)。

## 7. 怎样知道第一轮调研可以收尾？

当你已经能用自己的话解释任务分类，指出主要代表作及各自证据，说明两三项共同困难，并列出仍需讨论的问题，就可以进入下一次讨论。新论文若只重复已知内容，先登记，不必继续堆阅读报告。

如果有一周，可大致安排：第 1 天建立地图，第 2–3 天筛选和泛读，第 4–5 天重点阅读，第 6 天综合比较，第 7 天补证据、准备讨论。若只有一天，就缩小论文范围和阅读深度，明确哪些仍未核实。

## 与 AI 协作

可以让 AI 搜索候选、解释术语、定位证据和起草笔记；把自己不懂的地方反馈给它，比反复要求“更详细”更有效。对关键数字、图意、任务条件和较强的结论，回原始论文核对。

给 AI 的最小指令可以是：

> 请依据提供的论文，先用一段话说明任务、输入、目标、方法、主要结果及限制，再按阅读模板补充关键证据。区分作者报告的结果、你的归纳和待核实事项；标出 PDF 页码、节号或图表号。模型有代码链接不等于已经复现。先帮助我理解论文，再讨论它与其他工作的关系。
