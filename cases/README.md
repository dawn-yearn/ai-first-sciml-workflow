# 案例记录约定

这里连接通用工作流与未来具体论文的实践。目前只有记录约定，**尚无已完成的复现实例**。

选定论文后，为它建立一个以稳定论文编号命名的小目录，例如：

```text
cases/P001/
  README.md             # 论文、实现入口、当前状态与结论
  reproduction.md       # 从复现模板复制，写计划与结果
  extension-E001.md     # 有扩展实验后再创建
```

每项结果指向其代码版本、配置、运行命令和原始产物。大数据、权重、外部代码及实际运行目录在各课题的工作空间中管理，公开案例只保留适合分享的材料及明确的获取／重做说明。

首次练习先完成一个可核验结果。README 中写清完成的是最小运行、权重评价、重新训练还是独立重实现，不用一个笼统的“成功”覆盖全部工作。

入口：[选择模板](../templates/paper-selection.md)、[复现模板](../templates/reproduction-plan.md)、[扩展模板](../templates/experiment-note.md)。
